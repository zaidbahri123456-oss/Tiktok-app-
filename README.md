# 🎬 TikTok Clone App

A modern TikTok-style video sharing application built with React and Firebase.

---

## 🚀 Features

- 📱 TikTok-style vertical swipe feed
- 🎥 Auto-playing videos
- ❤️ Like system with animations
- 💬 Comments section
- 🔖 Bookmark/save videos
- 📤 Share functionality
- 🔥 Firebase backend integration
- 🌍 Arabic & English support
- 📱 Mobile optimized (responsive design)

---

## 🛠️ Tech Stack

- React.js
- Firebase (Auth, Firestore, Storage)
- Framer Motion (animations)
- JavaScript (ES6+)
- CSS / Inline styling
